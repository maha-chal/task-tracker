# My AI Coding Playbook

> My personal playbook for working with AI coding tools. Living document —
> revise as my practice changes.

## 1. When I reach for AI first
- Ensuring all relevant files are updated after an executed change
- Adjusting and fine-tuning documents
- Handling a well-known process that takes effort and time

## 2. When I do not reach for AI
- Judging/deciding critical options
- Subjective input
- Input based on own analysis

## 3. My non-negotiables
- Never share private information or data — no data in this course exposes my email, phone number, or even name
- Never rely blindly on output without understanding it — following the course videos, the prompt library, and the AI's explanations, I consider that I understand the output
- Always verify before committing — several times I considered the "Optional follow-up prompt" the AI proposed before committing (to follow the course trend), and I ask several questions before committing to ensure I understand the output

## 4. My review rules
- Check for hallucinated outputs — no hallucinations surfaced in this course, but usually I check every output for any invented link/number if available
- Confirm the output meets the prompt request specifically — e.g., each created file (architecture-A.md, ai-usage.md, ai-playbook.md) was reviewed to match the prompt requirement
- Ensure concise output — e.g., created files like README.md and CLAUDE.md were reviewed to check conciseness; git history shows I authored and refined these earlier in the course, restructuring CLAUDE.md into 7 required sections and making several README edits

## 5. What I am still figuring out
- How to ensure the full output is coherent from start to end
- How to know a review has been done properly
- How to ensure the output lands well with the reader

---

### Decision Card
- For a new feature I reach for: fine-tuning the feature
- For a code review I reach for: auditing and testing
- For debugging I reach for: checking line by line
- For infrastructure I reach for: robustness
- I will never paste personal data into an AI tool.
- My one rule is: keep verifying and inspecting the output
